# Platform Install

This skill is packaged as a plain folder and can be installed by symlink or copy.

## Codex

Default target:

- `~/.codex/skills/research-pipeline-automation`

## Claude Code

Conventional target used by the installer:

- `~/.claude/skills/research-pipeline-automation`

If a different skills root is used in the local setup, pass `--target-root`.

## OpenClaw

Conventional target used by the installer:

- `~/.openclaw/skills/research-pipeline-automation`

If a different skills root is used in the local setup, pass `--target-root`.

## Install Modes

- default: symlink
- optional: copy

Use the bundled install scripts in `scripts/`.
